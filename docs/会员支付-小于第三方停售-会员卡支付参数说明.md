# 会员支付（小于第三方停售）分支 - 会员卡支付接口参数说明

## 一、分支与调用时机

- **分支**：M6.5（会员支付且 **小于等于** 第三方停售时间，即 `timeGreaterThanLock === false`）。
- **入口**：选座页点击「确认选座」→ 走会员分支 M → 通过 M6.2 购买限制 → M6.3 时间判断为「距开场 ≤ lock_minute」→ 进入 M6.5。
- **流程**：不跳转 confirm-pay，在本页弹出「会员卡密码」弹窗；用户输入密码点「确认支付」后调用 **`cardApi.memberCardPayTicket`**，对应后端 **`POST /api/member/member_card_pay`**。

---

| 项目 | 说明 |
|------|------|

## 三、参数一览与取值来源

所有参数在 **M6.5 弹窗时** 写入 `_memberCardPayCtx`，或在 **用户点「确认支付」时** 在 `_doMemberCardPayInSeatSelect` 内计算，再传给 `memberCardPayTicket`。

| 参数名（请求 body） | 类型 | 取值来源 | 说明 |
|--------------------|------|----------|------|
| **cid** | string | `ctx.cinemaId` | 影院 ID。M6.5 弹窗时计算：`orderData.cinema_id \|\| orderData.cinemaId \|\| app.globalData.cinemainfo.cinemaid/cinemaNumber/id`，来自当前选座页订单或全局影院信息。 |
| **card** | string | `ctx.cardNumber` | 会员卡号。来自 `app.globalData.cardinfo.cardNumber \|\| cardinfo.card_no`，在 onConfirm 会员分支里取到后写入 ctx。 |
| **password** | string | 用户输入 → MD5 | 会员卡密码。用户在弹窗输入的明文，在 `_doMemberCardPayInSeatSelect` 内做 **MD5 32 位小写**：`md5(plainPassword).toLowerCase()`。 |
| **play_id** | string | `ctx.playId` | 场次 ID。来自选座页 `this.data.playId`，onLoad 时由页面参数 `options.playId` 写入。 |
| **seat_list** | string | `ctx.selectedIds` | 座位 ID 列表，逗号分隔。来自 `this.data.selectedIds`（用户点选座位时维护），cardApi 内会把数组 `join(',')` 成字符串。 |
| **partner_buy_ticket_id** | string | `ctx.partnerBuyTicketId` | 合作方购票单号，唯一。M6.5 弹窗时生成：`'' + Date.now() + orderId`，与 confirm-pay 卖品支付规则一致。 |
| **num** | number | 订单合计金额（元）取整 | 订单多少元就传多少（例如 35 元 → num=35）。在 `_doMemberCardPayInSeatSelect` 里：`Math.round(Number(total))`，与鼎新约定一致，避免「支付金额和商品价值不符」。 |
| **goods_card_balance_pay** | string | 订单总价两位小数 | 会员卡扣款金额（元）。在 `_doMemberCardPayInSeatSelect` 里：`total != null && total !== '' ? Number(total).toFixed(2) : '0.00'`。`total` 来自 ctx，为 onConfirm 时算的 `unitPrice * selectedIds.length`。 |
| **mobile** | string | 当前用户手机号 | 登录用户手机号。`app.globalData.supabaseUser.phone \|\| supabaseUser.mobile`，并去掉 `+86` 前缀（`.replace(/^\+?86/, '').trim()`）。 |
| **total** | string（可选） | `ctx.total` | 订单总价（数字转字符串）。同上，来自 `unitPrice * selectedIds.length`，用于后端展示或对账。 |
| **out_trade_no** | string（可选） | `ctx.outTradeNo` | 商户订单号。M6.5 分支固定为 `'mcyy-wechat-cardlj-' + orderId`，在 M6.3 之后、弹窗前已写入订单并放入 ctx。 |
| **order_id** | string（可选） | `ctx.orderId` | 本系统订单 ID。来自 `this.data.orderId`，onLoad 时由页面参数 `options.orderId` 写入。 |

## 四、数据流简图

```
onLoad(options)
  → playId = options.playId, orderId = options.orderId
  → order = app.globalData.playOrder
  → unitPrice = priceDetails?.unitPrice ?? order?.unit_price

用户选座
  → selectedIds, selectedNames 写入 this.data

点击「确认选座」onConfirm()
  → total = unitPrice * selectedIds.length
  → 会员分支 M → M6.2 → M6.3
  → timeGreaterThanLock === false 进入 M6.5
  → memberOutTradeNo = 'mcyy-wechat-cardlj-' + orderId
  → cinemaId = orderData.cinema_id || ... || cinemainfo.id
  → partnerBuyTicketId = '' + Date.now() + orderId
  → setData({ _memberCardPayCtx: { updatedOrderData, cardNumber, cinemaId, playId, selectedIds, selectedNames, total, orderId, outTradeNo: memberOutTradeNo, partnerBuyTicketId } })
  → showMemberCardPasswordModal = true

用户输入密码并点「确认支付」
  → onMemberCardPasswordConfirm() → _doMemberCardPayInSeatSelect(ctx, plainPassword)
  → passwordMd5 = md5(plainPassword).toLowerCase()
  → num = Math.round(Number(total))，goods_card_balance_pay = Number(total).toFixed(2)
  → cardApi.memberCardPayTicket({ cid, card, password, play_id, seat_list, partner_buy_ticket_id, num, goods_card_balance_pay, mobile, total, out_trade_no, order_id })
```
