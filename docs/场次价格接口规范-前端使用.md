# 场次价格接口规范（前端使用）

适用范围：App / H5 / 小程序 / Web  
维护方：价格管理中心  
重要级别：🔥 高（影响所有列表页性能）

---

## 一、价格类型说明（必须理解）

| 类型   | 字段            | 使用场景                     |
|--------|-----------------|------------------------------|
| 展示价 | display_price   | 排期列表页 / 首页 / 搜索页   |
| 成交价 | final_price     | 场次详情 / 下单 / 锁座       |

**❗ 列表页严禁使用成交价**

---

## 二、排期列表页价格接口

### 接口用途

- 获取场次基础信息
- 获取 **展示价（缓存价）**
- 用于列表渲染，**不区分用户身份**

### 接口定义

`GET /api/plays`

### 请求参数

| 参数        | 类型   | 必填 | 说明           |
|-------------|--------|------|----------------|
| cinema_id   | string | 否   | 影院编码       |
| movie_id    | string | 否   | 影片编码       |
| date        | string | 否   | 放映日期 YYYY-MM-DD |
| page        | number | 否   | 页码           |
| page_size   | number | 否   | 每页数量       |

### 返回示例

```json
{
  "list": [
    {
      "play_id": 123456,
      "start_time": "2026-02-10T19:30:00+08:00",
      "movie_name": "流浪地球 3",
      "movie_format": "IMAX",
      "display_price": 39.9
    }
  ],
  "page": 1,
  "page_size": 20,
  "total": 126
}
```

### 字段含义

| 字段           | 类型   | 说明           |
|----------------|--------|----------------|
| play_id        | number | 场次 ID        |
| start_time     | string | 放映时间       |
| movie_name     | string | 影片名称       |
| movie_format   | string | 放映格式       |
| display_price  | number | 展示价（缓存） |

### 前端展示规则

- 列表页展示：**¥39.9 起**
- 展示价是「最低可售价参考」，实际成交价可能因身份/活动变化

### 兜底规则（极少发生）

```js
if (display_price == null) {
  // 使用基础票价或占位（如 row.price / row.unit_price 或 "--"）
}
```

## 三、场次详情页 / 下单价格接口

### 接口用途

- 获取当前用户的 **最终成交价**
- 用于选座、下单、支付

### 接口定义

`POST /api/price/calc`

### 请求参数示例

```json
{
  "play_id": 123456,
  "channel_code": "app",
  "sale_stage": "normal"
}
```

### 返回示例

```json
{
  "play_id": 123456,
  "base_price": 49.9,
  "final_price": 39.9,
  "service_fee": 0,
  "applied_scheme": "vip",
  "rule_type": "fixed"
}
```

### 返回字段说明

| 字段           | 说明             |
|----------------|------------------|
| base_price     | 原价             |
| final_price    | 当前用户成交价   |
| service_fee    | 服务费           |
| applied_scheme | 命中身份         |
| rule_type      | 命中规则类型     |

---

## 四、性能与缓存说明（前端必读）

- **列表页**：使用缓存价，可前端缓存、可 CDN 缓存，不依赖用户。
- **禁止行为**：列表页调用算价 RPC、列表页按 user_id 算价、轮询算价接口。

---

## 五、展示价数据来源（本小程序）

展示价来自 Supabase 排期视图，与 `price_play_cache` 的关联由视图完成，前端**不再调用 RPC 算价接口**。

### 视图 / SQL 约定

排期数据需包含 `display_price`，来源为：

```sql
SELECT
  p.play_id,
  p.start_time,
  p.movie_name,
  c.display_price
FROM v_meicity_cinema_play p
LEFT JOIN public.price_play_cache c
  ON c.play_id = p.play_id
ORDER BY p.start_time;
```

即：`v_meicity_cinema_play` 需提供带 `display_price` 的视图（或等价视图 LEFT JOIN `price_play_cache`），供 `getCinemaPlay` 查询。

### 本小程序已实现

- **play 页**、**imax 页** 排期列表：仅调用 `supabase.getCinemaPlay()`，从返回的每行取 `row.display_price`（无则兜底 `row.price` / `row.unit_price`），列表展示「¥xx 起」；未登录也展示（不区分用户身份）。
- **已取消**列表页对 RPC 价格接口的调用（不再调用 `calcTicketPrice` / `_calculatePricesForShowtimes`）；成交价仅在选座、下单时通过 `getPriceDetails` 获取。
- 兜底：某场次无 `display_price` 时，使用排期行 `price/unit_price` 或占位「--」。
