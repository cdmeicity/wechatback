# 调起微信支付的参数与生成规则

## 一、流程概览

1. **前端** 调用 `saopayRequest.miniPay(businessParams)` → 请求 **POST /api/payment/mini-pay**
2. **后端（扫呗）** 返回 `code`、`paymentParams`（或 `data`）等
3. **前端** 从响应中解析出 `_parseWeChatPayParams` → 得到收银台参数
4. **前端** 调起 `wx.requestPayment(payParams)` → 微信收银台

---

## 二、请求 mini-pay 的完整参数（POST body）

请求体 = **公共参数** + **业务参数**，若配置了 `saopayFrontSignSecret` 还会追加 **sign**。

### 2.1 公共参数（`saopayRequest.getCommonParams()`）

| 参数名     | 类型   | 生成规则 |
|------------|--------|----------|
| **appid**  | string | 优先 `app.globalData.saopayAppid`，否则 `wx.getAccountInfoSync().miniProgram.appId`，再否则默认 `'wx46e9e8119f9686a4'` |
| **timestamp** | string | 当前时间秒级：`Math.floor(Date.now() / 1000)` 转字符串 |
| **nonce**  | string | 随机串：`'n' + Math.random().toString(36).slice(2, 15) + Math.random().toString(36).slice(2, 10)` |

### 2.2 业务参数（各场景传入的 businessParams）

| 参数名           | 类型   | 含义 | 生成规则 |
|------------------|--------|------|----------|
| **pay_type**     | string | 支付类型 | 固定 `'010'`（小程序支付） |
| **total_fee**    | string | 订单金额（**分**） | 见下方「各场景 total_fee 规则」 |
| **terminal_trace** | string | 商户订单号 | 仅取订单的 `out_trade_no`，无兜底；无则提示「订单号异常，无法支付」不发起支付 |
| **terminal_time** | string | 终端交易时间 | `yyyyMMddHHmmss`，如 `pad(n) = n<10 ? '0'+n : String(n)`，再拼 `年+月+日+时+分+秒` |
| **sub_appid**     | string | 小程序 appId | 同公共参数 appid 来源，可为空（后端可默认） |
| **open_id**       | string | 用户 openid | `app.globalData.wxProfile.openid` 或 `auth.getOpenid()` |
| **notify_url**    | string | 支付结果回调地址 | 固定 `'https://saopay.meicity.net/api/notify/payment'` |

### 2.3 签名（可选）

- 若配置了 `app.globalData.saopayFrontSignSecret`：
  - 除 `sign` 外所有字段，value 转字符串 trim，按 **key 字典序** 拼接成 `k1=v1&k2=v2&...`
  - 待签串：`上面拼接串 + "&key=" + secret`
  - **sign** = 对上述字符串做 **MD5，32 位小写**

## 三、各场景参数生成规则

### 3.1 确认支付页（卖品/影票补支付）— `confirm-pay.js`

| 参数 | 规则 |
|------|------|
| **total_fee** | 订单应付金额（元）× 100 取整，再转字符串。`totalInCents = Math.round(parseFloat(grandTotal) * 100)`，其中 `grandTotal` 为页面「合计」金额（含优惠券扣减）；onLoad 时 `totalInCents = Math.round(total * 100)` |
| **terminal_trace** | 仅 `order.out_trade_no`；无则提示并中止 |
| **terminal_time** | 当前时间 `yyyyMMddHHmmss` |

### 3.2 选座页-非会员微信支付（N7 分支）— `seat-select.js`

| 参数 | 规则 |
|------|------|
| **total_fee** | 选座订单总价（元）× 100 取整：`Math.round(total * 100)`，`total = unitPrice * selectedIds.length`（同 onConfirm 时计算） |
| **terminal_trace** | 仅订单的 `out_trade_no`（N7 分支先写入订单再弹窗，传该值）；无则提示并中止 |
| **terminal_time** | 当前时间 `yyyyMMddHHmmss` |

### 3.3 新办会员卡支付 — `card-manage.js` → `_requestWechatNewCardPay`

| 参数 | 规则 |
|------|------|
| **total_fee** | 订单金额（分）取整转字符串：`String(Math.round(Number(totalCents)))` |
| **terminal_trace** | 仅订单的 `out_trade_no`（即传入的 outTradeNo）；无则提示并中止 |
| **terminal_time** | 当前时间 `yyyyMMddHHmmss` |

### 3.4 会员卡充值支付 — `card-manage.js` → `_requestWechatCardPayAndPay`

| 参数 | 规则 |
|------|------|
| **total_fee** | 充值金额（分）取整转字符串：`String(Math.round(Number(totalCents)))`，totalCents 一般来自充值金额（元）× 100 |
| **terminal_trace** | 仅订单的 `out_trade_no`（即传入的 outTradeNo）；无则提示并中止 |
| **terminal_time** | 当前时间 `yyyyMMddHHmmss` |

## 四、mini-pay 响应 → 收银台参数解析

成功时响应体包含 `code === 200`（或 `'200'`）以及 **paymentParams**（或 `data` 或根对象）。

### 4.1 解析逻辑（`_parseWeChatPayParams` / `_parseWeChatPayParamsForN7`）

- 原始对象：`raw = data.paymentParams || data.data || data`
- 映射关系（兼容多种命名）：

| 收银台参数（wx.requestPayment） | 取值优先级（raw 中的 key） |
|--------------------------------|----------------------------|
| **timeStamp**                   | `raw.timeStamp` → `raw.timestamp` |
| **nonceStr**                    | `raw.nonceStr` → `raw.noncestr` |
| **package**                     | `raw.package` |
| **signType**                    | `raw.signType` → `raw.sign_type`，默认 `'MD5'` |
| **paySign**                     | `raw.paySign` → `raw.pay_sign` → `raw.sign` |

- 若 `timeStamp`、`nonceStr`、`package`、`paySign` 任一为空则解析失败，返回 null。

### 4.2 调起微信收银台（wx.requestPayment）

传入对象：

```js
{
  timeStamp: string,   // 时间戳
  nonceStr: string,    // 随机串
  package: string,     // 预支付会话 id（如 prepay_id=xxx）
  signType: string,    // 一般为 'MD5'
  paySign: string,     // 签名
  success: function,   // 支付成功回调
  fail: function       // 支付失败/取消回调
}
```

以上 5 个字段均来自 mini-pay 返回的 paymentParams，由前端解析后原样传给 `wx.requestPayment`，**不在此文档中再次生成**。
