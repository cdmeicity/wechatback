# 缺少用户提示的清单

本文档列出程序中「应有提示/报错但此前缺失或被注释」的位置，便于后续补全。

---

## 一、seat-select 选座页（已补全）

| 场景 | 位置 | 说明 | 状态 |
|------|------|------|------|
| 会员订单确认失败 canBuy=false | M6.2 | 接口返回无法购票，需提示原因 | ✅ 已加 wx.showToast |

| 非会员锁座失败 N6 | nonmember/seat_lock 返回失败 | 需提示锁座失败原因 | ✅ 已加 wx.showToast |
| 非会员锁座异常 NL1 | nonmember/seat_lock catch | 需提示请重试 | ✅ 已加 wx.showToast |

## 三、其他页面（建议排查）

- **confirm-pay**：支付方式失败、会员卡支付失败、微信支付取消等是否有明确提示。
- **card-manage**：绑卡/解绑/充值/查询失败时是否有 Toast/Modal。
- **coupon-bind / coupon-list**：券绑定失败、列表加载失败是否有提示。
- **order / order-list**：订单列表为空、加载失败、操作失败是否有提示。
- **play / index**：影片或排期加载失败时，除 loading 外是否有「加载失败」类提示。

---

## 四、说明

- 已补全项均在 `miniprogram/pages/seat-select/seat-select.js` 中实现。
- 文案以后端返回的 message/desc/content 优先，无则使用上述默认文案。
- 其他页面可按同样方式排查：凡「失败/异常/限制」分支在只打 log 不弹窗时，建议补 wx.showToast 或 wx.showModal。
